PokeKnomiGochi

A Pokémon tamagotchi for the BTT Knomi V2. Install it from your browser, with nothing to set up.

1. Plug in your Knomi

  1. Use Chrome or Edge on a computer. Other browsers can't talk to USB devices.
  2. Connect the Knomi V2 with a USB-C data cable. Charge-only cables won't work.

2. Install

This browser can't flash devices. Use Chrome or Edge on a computer. The installer needs an HTTPS page.

Pick the USB serial port when asked, usually named CH340 or wchusbserial. It takes a few minutes, so keep the Knomi plugged in.

Updating? Leave Erase device unticked to keep your Pokémon. Ticking it deletes the game and the saved Wi-Fi.

3. Play

Choose your starter and tap the egg to hatch it. For the clock, swipe down, then swipe left and tap Change Wi-Fi.

This replaces the printer-status firmware on the Knomi. The README explains how to go back, and how to fix a port that doesn't show up.
